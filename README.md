# 찍계부

카드 사용내역 스크린샷을 읽어 지출 후보를 만들고, 확인 후 저장하는 아이폰용 PWA 프로토타입입니다.

## 실행 및 설치

1. 저장소의 **Settings → Pages**를 엽니다.
2. Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 **Save**를 누릅니다.
3. 배포가 완료되면 https://wh101f-coder.github.io/jjikgyebu/ 를 아이폰 Safari로 엽니다.
4. Safari 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.

## 기능

- 카드내역 스크린샷 여러 장 선택 및 한국어/영어 OCR
- 날짜, 업체명, 금액, 카드사 후보 추출 및 업종 분류
- 연속 스크린샷의 겹친 거래를 보수적으로 제외
- 등록 전 업체명, 금액, 카테고리 수정
- 지출 직접 등록, 수정, 삭제 및 월별 합계

## 데이터와 인식 범위

스크린샷 OCR은 브라우저에서 수행합니다. OCR 엔진과 언어모델은 인터넷에서 내려받으므로 처음 분석할 때 인터넷 연결이 필요합니다. 거래는 현재 브라우저의 localStorage에 저장하며 서버 DB나 다른 기기로 동기화하지 않습니다. 브라우저 데이터를 지우면 거래도 삭제됩니다.

카드앱마다 화면이 달라 자동 추출 결과에는 오류가 생길 수 있습니다. 실제 카드내역과 비교하고 확인한 뒤 등록하세요. 현재 자동 추출 대상은 카드사이며, 개별 카드 상품명은 별도 자동 추출하지 않습니다.

## 구성

`index.html`, `styles.css`, `app.js`: 화면 및 거래 처리

`manifest.webmanifest`, `sw.js`, `icons/`: 홈 화면 설치 및 앱 화면 캐시

GitHub Pages는 이 저장소의 루트 파일을 게시합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.
